# CAN in Automation (CiA)

This directory is a local-only place for the CiA specification documents.
The PDFs are copyrighted by CAN in Automation (CiA) and must **not** be
committed or redistributed. All `docs/cia/*.pdf` files are ignored by git.

Place the following versions here if you need the specification text:

| Specification | Expected version |
|---------------|------------------|
| CiA 306-1 | v1.4.0 |
| CiA 306-2 | v1.2.0 |
| CiA 306-3 | v1.2.0 |
| CiA 311 | v1.1.0 |

The CiA 311 XML schema (XSD) is kept in the repository as a test fixture under
`tests/EdsDcfNet.Tests/Fixtures/Schemas/cia-311/`. See the `NOTICE.md` there for
its origin and terms. The specification documents themselves are not part of the
repository.
